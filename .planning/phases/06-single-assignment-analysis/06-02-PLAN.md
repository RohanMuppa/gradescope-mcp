This module assembles the multimodal content blocks that will be returned as the MCP tool response for `analyze_submission`. The key difference from `formatAsMultimodalContent` (Phase 5) is ordering: images FIRST, then the analysis prompt text. Phase 5's formatter put the summary text first then images, which is fine for viewing but suboptimal for analysis.

Import `TextContent` and `ImageContent` from `@modelcontextprotocol/sdk/types.js`.
Import `SubmissionPage`, `QuestionScore`, `RubricAndFeedback` from `../gradescope/types.js`.
Import `determineTargetPages` from `../content/page-targeter.js`.
Import `log` from `../utils/logger.js`.

**Function 1: `identifyLostPointQuestions`**

```typescript
export function identifyLostPointQuestions(
  rubricData: RubricAndFeedback
): QuestionScore[] {
  return rubricData.questionBreakdown.filter(
    (q) => q.score < q.maxScore && q.status === "graded"
  );
}
```

Per locked decision: only analyze questions where points were lost. Skip full-mark questions entirely.

**Function 2: `collectTargetPages`**

```typescript
export function collectTargetPages(
  lostPointQuestions: QuestionScore[],
  totalPages: number,
  pageMappings: PageMapping[] | null
): number[]
```

For each lost-point question, call `determineTargetPages(totalPages, question.name, pageMappings, Infinity)` to get its pages (pass Infinity for pageCap since we don't want per-question capping — we send all relevant pages). Merge all page numbers into a deduplicated, sorted array.

If no page mappings exist (pageMappings is null), fall back to all pages up to a reasonable limit (use `determineTargetPages(totalPages, undefined, null)` which returns all pages up to the default cap).

Import `PageMapping` from `../gradescope/types.js`.

**Function 3: `assembleAnalysisContent`**

```typescript
export function assembleAnalysisContent(
  submissionPages: SubmissionPage[],
  analysisPrompt: string,
  metadata: {
    courseName: string;
    assignmentName: string;
    totalPages: number;
    pagesIncluded: number;
    questionsAnalyzed: number;
  }
): Array<TextContent | ImageContent>
```

Build the content blocks array in this order:

1. **Brief context text block** (first): A short line like "Grade defense analysis for {assignmentName} ({courseName}). Analyzing {questionsAnalyzed} questions across {pagesIncluded} of {totalPages} pages."

2. **Page images with labels** (images FIRST per Claude vision best practices): For each submission page:
   - Text block: `"--- Page {pageNumber} ---"`
   - Image block: `{ type: "image", data: base64, mimeType: page.mimeType }`
   - After encoding to base64, set `(page as any).imageBuffer = null` to release the buffer for GC (same pattern as multimodal-formatter.ts)

3. **Analysis prompt text block** (LAST): The full analysis prompt string with all rubric data and instructions.

Return the complete array of content blocks.

Log at DEBUG level: number of pages included, number of content blocks generated.
