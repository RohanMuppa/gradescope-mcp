<objective>
Create the `analyze_submission` MCP tool that composes rubric data and submission images into a single multimodal analysis request.

Purpose: This is the user-facing tool — the "killer feature." It takes a course and assignment identifier, fetches the rubric breakdown AND the submission content, filters to lost-point questions only, assembles everything into properly ordered multimodal content blocks (images first, analysis prompt last), and returns them. Claude (the MCP client) then processes these content blocks to produce the actual grade defense analysis. The tool is a data composer, not an analysis engine — it assembles the right context for Claude to reason about.

Output: `src/mcp/tools/analyze-submission.ts` registered in `src/mcp/server.ts`.
</objective>

**Input schema:**
```typescript
z.object({
  course: z.string().describe("Course ID or course name (fuzzy match, e.g., 'CS 250' or '12345')"),
  assignment: z.string().describe("Assignment ID or assignment name (e.g., '54321' or 'Homework 3')"),

})
```

**Tool metadata:**
- name: `"analyze_submission"`
- title: `"Analyze Graded Submission"`
- description: `"AI-powered grade defense analysis for a specific graded assignment. Compares submission content against rubric to identify where points may have been incorrectly deducted. Returns submission images and a structured analysis prompt for Claude to process. Results should be framed as potential opportunities to investigate, not definitive claims."`

**Implementation flow (inside the handler):**

1. **Resolve course** — fuzzy match (same as get-submission.ts steps 1-2). Error: [GSMCP-1031].

2. **Resolve assignment** — 4-tier match (same as get-submission.ts steps 3-4). Error: [GSMCP-1032]. Check graded: [GSMCP-1035].

3. **Fetch rubric data** — Same HTML fetch as get-rubric-and-feedback.ts step 5-6:
   ```typescript
   const submissionPath = `/courses/${matchedCourse.id}/assignments/${matchedAssignment.id}`;
   const html = await gsClient.getText(submissionPath, { forceRefresh: forceRefresh ?? false });
   const rubricData = parseRubricAndFeedback(html);
   ```
   Import `parseRubricAndFeedback` from `../../gradescope/parsers/rubric.js`.

4. **Identify lost-point questions** — Call `identifyLostPointQuestions(rubricData)` from `../../analysis/content-assembler.js`. If empty (no lost points), return a text-only response via `toolResponse()`:
   ```typescript
   return toolResponse({
     status: "no_findings",
     message: `No points were lost on ${matchedAssignment.name}. Score: ${rubricData.totalScore ?? matchedAssignment.score}/${rubricData.totalMaxScore ?? matchedAssignment.maxScore}. No analysis needed.`,
     course: { id: matchedCourse.id, name: matchedCourse.name },
     assignment: { id: matchedAssignment.id, name: matchedAssignment.name },
   });
   ```

5. **Parse submission page for download metadata** — Call `parseSubmissionPage(html)` to get download URL, content type, page mappings, total pages. Import from `../../gradescope/parsers/submission.js`.

6. **Collect target pages** — Call `collectTargetPages(lostPointQuestions, totalPages, submissionContent.pageMappings)` from `../../analysis/content-assembler.js`. This gives the deduplicated, sorted list of page numbers relevant to all lost-point questions.

7. **Download and convert submission pages** — Use the EXACT same 3-path content download logic from get-submission.ts (PDF, scanned exam per-page, single image). Download only the target pages. Import `convertPDFToImages` from `../../content/pdf-converter.js` and `optimizeForClaudeVision` from `../../content/image-optimizer.js`. Same MAX_BINARY_SIZE = 50MB check.

8. **Build analysis prompt** — Call `buildAnalysisPrompt(rubricData, lostPointQuestions, { courseName, assignmentName, totalScore, maxScore })` from `../../analysis/prompt-builder.js`.

9. **Assemble multimodal content** — Call `assembleAnalysisContent(submissionPages, analysisPrompt, metadata)` from `../../analysis/content-assembler.js`.

10. **Return MCP response** — Return `{ content: contentBlocks }` as `CallToolResult`. This is a multimodal response (images + text), same pattern as get-submission.ts.

**Error handling:** Same try/catch pattern as get-submission.ts. Unknown errors get code [GSMCP-1037].

Import `CallToolResult` from `@modelcontextprotocol/sdk/types.js` (same as get-submission.ts uses TextContent, ImageContent).
